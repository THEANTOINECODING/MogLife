# MOG LIFE 💪

Jeu Roblox de musculation humoristique.

## Démarrer une session de travail

1. Lancer la synchronisation (laisser le terminal ouvert) :
   ```bash
   rojo serve
   ```
2. Ouvrir Roblox Studio (Baseplate), onglet **Plugins** ⟩ **Rojo** ⟩ **Connect**
3. Ouvrir Claude Code dans ce dossier

## Après un nouveau clone du projet

```bash
rokit install
```
```bash
wally install
```
