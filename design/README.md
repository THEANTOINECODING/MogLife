## Règles d'organisation

1. **Une nouvelle idée va d'abord dans `IDEES.md`.** Jamais directement dans le design.
2. Une idée passe dans le design seulement après une décision notée dans `DECISIONS.md` (date, choix, raison).
3. Les `❓` signalent une question ouverte : c'est au créateur de trancher, pas à l'IA.
4. Les chiffres sont des **hypothèses** jusqu'à validation par simulation puis par tests joueurs.
5. `archive/` garde les anciennes versions pour référence ; elles ne font plus foi.
