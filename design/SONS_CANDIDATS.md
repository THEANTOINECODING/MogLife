# Sons candidats (à écouter avant de les mettre dans le jeu)

Décision du créateur (16/10) : Claude propose, le créateur écoute et choisit. Claude ne peut pas entendre les sons.
Pour écouter : ouvrir le lien (Creator Store) et appuyer sur lecture. Pour choisir : donner à Claude le nom du
son et l'emplacement (ou coller l'identifiant `rbxassetid://…` dans `src/shared/Config/Sounds.luau`).

**Source sûre en priorité : `APMOfficial`**, la bibliothèque musicale sous licence fournie par Roblox (APM Music).
Les autres sons viennent de particuliers : à éviter s'ils copient un jeu ou un mème connu (droits d'auteur).
Déjà écartés pour cette raison : « FF7 Victory Fanfare », « Barret Victory Fanfare », « Jetpack Joyride… »,
« Poppy Playtime… », « Slime Rancher… », « Tenna Jingle ».
